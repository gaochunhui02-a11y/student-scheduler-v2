# Launch kit (drafts — nothing here has been sent or published)

| File | What it is |
|---|---|
| `landing-copy.md` | All copy on the public landing page, editable in one place |
| `product-description.md` | Short / medium / long descriptions for app stores, directories, bios |
| `demo-script.md` | A 90-second product demo script (screen recording or live) |
| `community-outreach.md` | A post for student communities (Reddit, Discord, university forums) |
| `founding-user-invite.md` | Personal invitation to become a founding user |
| `interview-questions.md` | 30-minute feedback interview guide |
| `launch-checklist-30-days.md` | Day-by-day 30-day launch checklist |

Rules for using these:

- Make only claims the product can back up today. Calendar *sync* isn't built, Pro isn't for sale, and the app can't promise better grades.
- Follow each community's self-promotion rules. Disclose that you're the maker.
- Only message people who opted in or whom you know. No bulk cold messaging.
