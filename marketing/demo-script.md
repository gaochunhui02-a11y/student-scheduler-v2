# 90-second demo script

Record from `/dashboard.html?demo=1` (sample data; no account needed). Use a browser window of about 1280×800 with light theme. Keep the cursor slow.

| Time | Screen | Voice-over |
|---|---|---|
| 0:00 | Landing page hero | "This is Student Scheduler. It plans your semester, and it fixes the plan when life gets in the way." |
| 0:08 | Click **Try the demo**; Today opens | "This is a normal busy week: five courses, labs, a midterm coming up." |
| 0:15 | Point at the **Do this next** card | "Today answers one question: what should I do next? Here it's an overdue lab prep, and I can start a focus timer right away." |
| 0:25 | Point at **3 tasks need a new day** | "I missed a few things last week. Instead of a red list of guilt…" |
| 0:30 | Click **Catch up**; the drawer opens | "…it finds time before each deadline. Every task says why. 'Friday has 2½ hours free, so it starts there.'" |
| 0:42 | Scroll to a task split over two days | "Bigger work gets split across days, and it never goes over my daily limit." |
| 0:50 | Hover **Apply plan** | "Nothing moves until I apply it. Locked sessions stay put, and nothing is deleted." |
| 0:55 | Apply → toast; back on Today | "Done. My week is realistic again." |
| 1:00 | Courses → **Import syllabus**, paste a schedule, **Read it** | "Starting a new course? Paste the syllabus." |
| 1:10 | Point at a **Needs confirmation** row | "It reads dates and exams, and anything ambiguous, like 3/4, waits for me to check it. It never invents a deadline." |
| 1:20 | Import → **Plan my deadlines** | "Import, and it's planned." |
| 1:25 | Landing page CTA | "Student Scheduler. Free during the beta. Your semester, planned automatically." |

Don't say "AI" (it isn't), don't promise grades, and don't show calendar sync (not built).
